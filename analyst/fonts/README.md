# Fonts of the PDF report

Embedded in the PDF report (as subsets: a report carries only the glyphs it uses), so that names and texts in any
of these scripts are printed instead of disappearing. Used by `analyst/typefaces.py`.

| File | Font | Scripts | License |
|---|---|---|---|
| `LiberationSans-Regular.ttf`, `-Bold.ttf`, `-Italic.ttf` | Liberation Sans 2.1.5 — same metrics as Helvetica, so the layout of the report is unchanged | Latin, Greek, Cyrillic | SIL Open Font License 1.1 (`OFL-1.1.txt`) |
| `DroidSansFallbackFull.ttf` | Droid Sans Fallback | Chinese (simplified and traditional), Japanese | Apache License 2.0 (`LICENSE-Apache-2.0.txt`) |
| `NanumGothic.ttf` | Nanum Gothic | Korean | SIL Open Font License 1.1 (`OFL-1.1.txt`) |
